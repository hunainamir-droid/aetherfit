# AetherFit – AI Workout Plan Architect

Personalized, science-based workout programs generated by **Gemma 4** (via the Gemini API).

- **Plan generator**: full weekly program with sets, reps, tempo, cues and nutrition guidance
- **AI coach**: form and technique questions answered per exercise
- **Exercise swap**: three alternatives that match equipment or joint limits

## How it works

```
React frontend (src/)  →  Express backend (server.ts)  →  Gemma 4 (Gemini API)
```

The browser only calls the local backend (`/api/workout/*`). The backend holds the API key and calls Google.

## Run locally

**Prerequisites:** Node.js 22+

1. Install dependencies:
   `npm install --legacy-peer-deps`
2. Copy `.env.example` to `.env` and set `GEMINI_API_KEY` to your key from https://aistudio.google.com/apikey
   (optional: `GEMMA_MODEL`, default `gemma-4-26b-a4b-it`)
3. Run the app:
   `npm run dev`
4. Open http://localhost:3000

> `.env` is git-ignored. Never commit your API key.

## Deploy (free, auto-updates)

The repo includes a [Render](https://render.com) Blueprint (`render.yaml`).

1. Sign in to Render with GitHub → **New → Blueprint** → pick this repo.
2. Enter your `GEMINI_API_KEY` when asked → **Apply**.
3. Every `git push` to `main` redeploys automatically.

Free instances sleep after 15 minutes idle; the first visit afterwards takes about a minute to wake up.
